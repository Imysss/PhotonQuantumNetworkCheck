# UX gap 체크리스트

"시스템은 처리하지만 사용자에게 안 보이는" 케이스 점검. ID는 [references/H-ux-gap.md](../references/H-ux-gap.md) 참조.

진단 모드에서 가장 놓치기 쉬운 영역 — 핸들러는 있어도 UI 컴포넌트가 연결 안 된 경우.

## 끊김 / 재접속 피드백

- [ ] **H1** 재접속 30s 타이머 작동 중 전용 오버레이 UI 표시.
- [ ] **H1** 카운트다운 (남은 시간) 명시.
- [ ] **H1** `OnLocalDisconnected` / `OnLocalReconnect*` 이벤트 구독하는 UI 컴포넌트 존재 확인.
- [ ] 이벤트 발화 코드 grep → 구독 코드도 grep → 미연결 이벤트가 없는지.

## 매칭 / 로딩 진행 표시

- [ ] **H2** 매칭 대기 중 silent 동작이라도 진행 표시(스피너/점선) 유지.
- [ ] **H2** 옵션 A(조용히) vs 옵션 B(피드백 있음) 정책 결정 + 코드 주석으로 명시.
- [ ] **H5** B10 timeout과 함께 단계별 메시지 변화 (0~5s, 5~15s, 15s+).
- [ ] **H5** 사용자가 직접 취소할 수 있는 출구 제공.

## 에러 / 실패 안내

- [ ] **H3** Desync 발생 시 모달 + "결과 화면으로" 버튼 (자동 종료도 OK).
- [ ] **H3** Desync 시 양쪽 모두 비정상 종료로 분류 (패배 처리 X 또는 무승부).
- [ ] **H4** Command 전송 실패 시 1~2회 자동 재시도.
- [ ] **H4** 재시도 모두 실패 시 사용자 토스트.
- [ ] **H4** Predicted input 적용 → 즉시 피드백.

## Silent retry 진행감

- [ ] **H6** A9 rematch 회피 retry 중 진행 표시 유지.
- [ ] **H6** A11 동시 매칭 사후 복구 중 진행 표시 유지.
- [ ] **H6** B8 AI 프로필 API 재시도 중 진행 표시 유지.
- [ ] **H6** 누적 대기 시간 임계 초과 시 약한 텍스트 변화.
- [ ] **H6** 단계별 텔레메트리 (어디서 retry가 자주 발생하는지).

## 진단 시 grep 패턴

UX gap을 찾기 위한 grep 키워드:

| 패턴 | 의미 |
|------|------|
| `\.Invoke(` + 같은 이벤트 이름 `+= ` 없음 | 발화하는데 구독 안 함 |
| `RLog.LogError(` + UI 코드 호출 없음 | 로그만 남고 사용자 피드백 없음 |
| `await UniTask.Delay(` + UI 갱신 없음 | 대기 중인데 진행 표시 없음 |
| `_isWaiting` / `_isLoading` 플래그 + UI bind 없음 | 상태는 있는데 표시 안 함 |
